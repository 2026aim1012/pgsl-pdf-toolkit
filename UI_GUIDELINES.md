# UI Guidelines

- Window: min 720p; default 1280x720.
- Toolkit: right side, vertical.
- Undo button: yes. No copies outside temp. Minimal undo state.
- Multi-select: Ctrl+click / drag. Hover highlight.
- Long tasks: worker thread + progress bar.
- Display centered.
- Resizable: grid snapping, adaptive button layout.
- Documents tab: folder/explorer-like.
- No version/app name inside canvas; use title bar.
- Every UI element must function in the end.
- Mimic ilovepdf accessibility where possible.
- Compression slider: limit quality loss.
